# 使用指南

## 创建用户并绑定设备

管理员负责管理服务；用户或角色用于划分数据空间。同一用户可以绑定多台设备。

1. 在 **用户管理** 中创建用户，例如家庭成员或使用场景。
2. 点击绑定设备，生成一次性设备码。设备码有效期为 10 分钟。
3. 在客户端填写服务器 HTTPS 地址和设备码，完成绑定。
4. 确认客户端显示的用户名称，再开始推送或下载。

支持 `vodplus://` 链接的客户端可以使用后台的一键绑定入口。

用户可以重命名或停用。设备可以重命名或撤销授权；撤销后需要重新绑定。停用用户会阻止其设备访问，并保留数据。

## 推送与下载

**推送**将本机数据写入云端。完整推送确认后，服务端会删除所选范围内没有出现在本次清单中的项目。

**下载**将云端数据应用到本机。恢复包中的内容会覆盖对应的本机数据，删除通知会删除对应项目。全部应用成功后，客户端才确认恢复完成。

不同客户端可以选择自己的数据范围与本地目录。具体按钮和存储位置由客户端提供。

## 文件管理

后台的 **爬虫管理 → 文件资源** 页面提供文件管理功能。先选择用户空间或公共库，再操作文件。

| 操作 | 说明 |
| --- | --- |
| 新建文件或目录 | 填写相对路径 |
| 上传文件 | 选择目标目录，并选择覆盖或自动重命名 |
| 拖放上传 | 将文件拖到页面，打开批量上传弹窗 |
| 编辑 | 点击文件名，在弹窗中查看、修改或替换内容 |
| 重命名 / 移动 | 输入目标相对路径，目标父目录需要存在 |
| 停用 | 保留内容，停止对外提供该项目 |
| 回收站 | 查看删除项目并恢复 |
| 历史版本 | 查看最近 20 个版本，恢复时生成一次新的记录 |

每层目录排在文件前面，默认收起；可以单独展开或一键展开、收起。桌面显示行内操作，小屏幕使用下拉菜单。

单文件最多 1.5 MiB。目录一次移动或删除最多包含 80 项，较大的目录需要分批处理。拖放上传支持文件，不递归导入整个本地文件夹。

公共库可独立发布，也可以将文件复制给用户。复制后的文件由目标用户独立维护。

## 同步规则

在 **爬虫管理 → 同步规则** 中设置文件类型和排除目录。

默认允许的后缀：

```text
py js txt json m3u8 jar php html
```

默认允许无后缀文件，排除以下目录及其全部子项：

```text
_cache
__pycache__
pycache
```

后缀和目录名忽略大小写。目录名在任意层级匹配；同名普通文件不按目录处理。后缀取文件名最后一个点之后的部分，例如 `archive.tar.gz` 的后缀为 `gz`。

调整规则不会清空已存内容。被排除的项目不因完整推送清单缺少它们而被删除。公共库的独立发布不受用户同步规则限制。

## 只读分享

在首页创建分享接口，填写名称、来源空间和发布目录。目录留空表示发布该空间中的全部有效文件。

- 密码留空时公开访问；设置密码时为 5–200 个字符。
- 分享链接没有固定到期时间。
- 修改密码或撤销凭证后，已签发的授权链接失效。
- 停用分享、用户或发布目录会阻止访问。
- 目录重命名后，分享继续指向同一目录。

分享入口为 `/s/{shareId}`。文件、配置索引和子资源都受分享权限控制。接口参数见 [API 参考](PROTOCOL.md#分享接口)。

## 设备配置

点击设备名称，查看设备上报的配置，并向该设备发送修改或请求实时取值。后台显示的确认结果来自设备回报；设备未连接时，保留最后一次回报和时间。

客户端接入方法见 [设备配置 API](DEVICE_CONTROL.md)。

## 账号与服务重置

在头像菜单或 **账号与数据** 中修改管理员密码。

在 **服务重置** 中可以清空云端业务数据并重新创建管理员。操作需要当前密码和确认文字 `RESET`，完成后设备需要重新绑定。

[查看账号与重置说明](ACCOUNT_RECOVERY.md)
