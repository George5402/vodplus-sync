# 管理员账号与服务重置

## 创建管理员

首次访问空数据库时，页面会引导创建管理员。账号最长 80 个字符，密码为 5–200 个字符。

服务不提供默认管理员密码。重新部署保留数据库中的账号和数据。

## 修改密码

打开头像菜单或 **账号与数据**，填写当前密码和新密码。修改成功后，所有后台登录会话失效，需要重新登录；设备授权和业务数据保持不变。

### 请求

`POST /api/admin/account/password`

鉴权：管理员会话 Cookie。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| currentPassword | string | 是 | 当前管理员密码 |
| newPassword | string | 是 | 新密码，5–200 个字符 |

```json
{
  "currentPassword": "current-password",
  "newPassword": "replacement-password"
}
```

成功返回 `200`：

```json
{"ok":true,"relogin":true}
```

## 重置服务

在后台 **服务重置** 页面点击清空按钮，输入当前密码和大写 `RESET` 后确认。操作通过网页完成。

重置将清空：

- 管理员账号、登录会话、用户和设备授权。
- JSON 记录、文件内容、目录、历史版本和回收站。
- 分享接口及访问凭证。
- 发布清单、恢复会话、同步记录和自定义规则。

完成后回到创建管理员页面，同步规则恢复默认。D1 数据库和 Worker 资源保留；客户端本地数据不会由此自动删除。

清空在数据库事务中执行，发生错误时整体回滚。成功后无法通过后台撤销。

### 请求

`POST /api/admin/account/reset`

鉴权：管理员会话 Cookie。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| currentPassword | string | 是 | 当前管理员密码 |
| confirmation | string | 是 | 固定值 `RESET` |

成功返回 `200`：

```json
{"ok":true,"initialized":false}
```

## 无法登录

先确认服务地址、账号和密码。显示登录页表示当前数据库已经有管理员。

忘记密码时，需要由持有 Cloudflare 账号权限的维护者处理账号恢复。公开接口不提供匿名改密或匿名清空功能。
