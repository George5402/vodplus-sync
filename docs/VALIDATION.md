# 开发与测试

## 环境

- Node.js 22 或以上。
- npm。
- Git。

安装依赖并启动本地开发：

```sh
npm ci --ignore-scripts
npm run dev
```

打开终端显示的地址。初次访问创建管理员，本地数据与 Cloudflare 数据分开保存。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动本地 Worker 和管理页面 |
| `npm run styles` | 编译 Tailwind CSS |
| `npm run check` | 检查服务端、前端和示例模块 |
| `npm test` | 执行自动测试 |
| `npm run build` | 编译样式并执行 Worker 打包检查 |
| `npm run db:local` | 应用本地数据库结构变更 |
| `npm run deploy` | 发布到 Cloudflare |

`build` 使用 Wrangler dry-run，不创建远端资源。

## 自动测试

测试位于 [tests/](../tests/)，通过 Miniflare 运行真实 workerd 与 D1 SQLite。测试数据库为隔离环境。

| 范围 | 主要检查 |
| --- | --- |
| 身份与权限 | 初始化、登录、设备码、用户隔离、设备撤销 |
| 数据推送 | 摘要一致零正文上传、按需补传、幂等请求、命名空间隔离、完整清单确认 |
| 文件 | 单行 BLOB 往返、数字 ID 稳定性、JSON 清单、并发原子更新、历史与回收站 |
| 恢复 | 固定快照、分页、确认、中断、过期和删除通知 |
| 同步规则 | 后缀、目录排除、规则修改与发布确认竞争 |
| 管理功能 | 分享、改密、重置、设备配置 |
| 数据库 | 自动补齐、事务回滚和迁移记录 |
| 查询消耗 | 500/1000 文件的单行清单读取、批量指纹比对、确认及恢复开销 |
| 客户端 SDK | 完整推送、恢复及本地 I/O 失败处理 |
| 部署 | 数据库选择、创建、发布顺序和失败处理 |

## 提交前检查

```sh
npm run check
npm test
npm run build
```

接口修改应同步更新参数、返回值和示例，并增加对应行为测试。数据库变更通过新增迁移文件完成，同时更新运行时结构检查。

文档修改应检查相对链接、接口路径和代码示例。仅修改文档时，不需要重复执行应用构建。

## 界面预览

```sh
node scripts/preview.mjs
```

预览服务使用内存示例数据，监听 `127.0.0.1:8799`。终端会显示测试登录信息；结束后关闭进程，数据随进程销毁。

## 验证范围

服务端测试验证协议和存储行为。客户端还需要在目标平台检查本地文件替换、数据库写入、应用生命周期和网络中断；这些应由客户端项目执行。

部署后可使用 `GET /api/health` 检查服务就绪状态。涉及清空数据的测试应在隔离环境进行。
